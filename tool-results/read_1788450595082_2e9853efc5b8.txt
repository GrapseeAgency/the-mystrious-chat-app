   424→[ Developer Designs Icon ] ---> [ Export to .SVG Code ] ---> [ Compile to SVG-Sprite / Icon Font ]
   425→                                                                       |
   426→+----------------------------------------------------------------------+
   427→|
   428→v

   431→
   432→* Why they never use normal emojis: System emojis do not support dynamic state styling (like changing color from grey to a custom glowing blue upon hover or press). They cannot be animated precisely through code and often clash with professional typography scales.
   433→* The Custom Icon Standard: To maintain a completely unique aesthetic, platforms implement custom vector icons. They serve these via two methods:
   434→1. SVG Sprites / Inline Vectors: Lightweight XML code strings rendered on-demand by the app's layout engine.
