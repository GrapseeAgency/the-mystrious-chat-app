## 1. Wire-contract gotchas (from audit — bindings, not guesses)
1. Poll create = `POST /api/conversations/{id}/poll`; NO `GET /api/polls/{id}` (poll rides `message.poll`).
2. Kanban board = `GET|POST /api/conversations/{id}/kanban`; cards = `PATCH|DELETE /api/kanban/{cardId}`. Columns exactly `todo|doing|done`; move w/o position → end of column; delete = creator OR group admin.
3. Events = `GET|POST /api/conversations/{id}/events`; `DELETE /api/events/{id}?userId=`; RSVP `POST /api/events/{id}/rsvp` `{userId,status: going|maybe|no}`; check-in `POST /api/events/{id}/checkin` — requires RSVP, window startsAt−15 min…+2 h, +15 XP, idempotent 409→200 `alreadyCheckedIn`.
4. Reminders: `GET /api/reminders?userId=[&due=1]` (due = remindAt ≤ now && firedAt null, order remindAt asc, take 100); POST `{userId, conversationId, messageId?, note? ≤280, remindAt ISO future ≤90 d}`; `PATCH|DELETE /api/reminders/{id} {userId}` owner-only. Client due-loop PATCHes firedAt after showing nudge.
5. Games: `POST /api/games {userId, conversationId, game?='tictactoe', opponentId?}` (creator=X, opponentId null = open O seat) → carrier message `kind='game'` payload `{"matchId","game"}`; `GET /api/games?conversationId=` newest 25; `GET /api/games/{id}` → `{match, playerX, playerO}`; `POST …/move {userId, cell 0..8}` (turn/occupied/409s; win +25 XP, draw +10 both, auto-feeds running tournament); `POST …/join {userId}` first-come O seat. **No abandonment exists server-side — do not invent it.**
6. Tournaments: `POST /api/tournaments {userId, conversationId, name ≤40}` → message `kind='tournament'` payload `{"tournamentId","name","game"}`; `GET ?conversationId=` newest 5 w/ playerCount; `GET /{id}` standings sorted points→wins→joinedAt; `PATCH /{id} {userId, status:'finished'}` creator/admin only, idempotent; `POST /{id}/join {userId}` idempotent upsert.
7. Leaderboard: `GET /api/leaderboard?conversationId=&userId=` (room, member-gated) or bare `GET` (global top 50). Rows `{userId,name,color,xp,messageCount,gameWins,tournamentPoints}` sorted tournamentPoints→gameWins→xp→name.
8. Red packets: `POST /api/redpackets {userId, conversationId, total 1..10000 int, count 1..50 int ≤ total, note? ≤60}` — atomic debit, precomputed whole-PC slices, 24 h expiry; carrier `kind='redpacket'` payload `{packetId,total,count,note}`; `GET /api/redpackets/{id}?userId=` (lazy refund on expiry; status open|exhausted|expired; grabs amount-DESC; myGrab; isMine); `POST …/grab {userId}` atomic — exact error strings: "You cannot grab your own red packet.", "You already grabbed this red packet.", "Someone grabbed at the same moment — try again." (409), etc.
9. Whiteboard: `/api/conversations/{id}/whiteboard` — coords normalized 0..1; `GET ?requesterId=&since=` → `{strokes[], serverTime, resetAt}`; `POST {requesterId, strokes:[{color,width,points[[x,y]…]}]}` (1..40 strokes × 2..500 pts, width 0.5..40, color ≤32) → `{ids[],created,serverTime}`; `POST {action:'undo', requesterId}` removes caller's latest; `DELETE ?requesterId=` clears all + resetAt watermark.
10. Hub: wallet `GET /api/hub/wallet?userId=[&ledger=30]` (upserts zero wallet; ledger desc); checkin `POST /api/hub/wallet/checkin` — 409 `{error:'Already checked in today. Come back tomorrow.', wallet}` (error body INCLUDES wallet); streak +25 base, +2/day bonus cap +20 (UTC day); transfer `POST /api/hub/wallet/transfer {userId,toUsername,amount 1..100000 int, note?≤140}`; swap `GET /api/hub/swap` rates `{pcPerGemBuy:100, pcPerGemSell:80}` + real stats, `POST {userId, direction: pc2gem|gem2pc, amount}` (pc2gem min/multiple 100); tasks `GET|POST /api/hub/tasks`, `PATCH|DELETE /{id}` owner-only; market `GET|POST /api/hub/market`, buy `POST /api/hub/market/{id}/buy {userId}` → **`{ok:true, wallet}`** (header comment lies — code truth); logs `GET /api/hub/logs?limit=&kind=` (`meta` is a RAW JSON STRING); apps: NO catalog GET (bundle `src/lib/hub-catalog.ts` MATRIX 100 apps + CATEGORY_META + APP_TAGLINES + BRAND_ACCENTS as shared JSON asset; appId = String(n)); install `GET|POST|DELETE /api/hub/apps/{appId}/install`; community `GET|POST /api/hub/apps/{appId}/community` (POST auto-provisions `#NNN · name community` group, founder admin); my-apps = fan-out per-app install GET (web hub-data.tsx:61,107) — replicate.
11. Auth: none — `userId` in body (writes) / query (reads). No cookies/headers.
12. XP rules: messages 2 XP, 250/day UTC cap (server); game win +25 / draw +10; check-in +15 — display only natively.

## 2. Native-native decisions (binding)
- **Message cards**: `kind=='redpacket'` → RedPacketCard (art + status + tap → detail/grab sheet); `kind=='game'` → TicTacToeCard (board, seats, turn, win-line strike, join/move; poll 1.5 s only while active and card visible); `kind=='tournament'` → TournamentCard (standings summary, join, finish for creator/admin). Payload parsed tolerantly from the raw JSON string.
- **Attach palette** (parity rows added to the existing attach sheet): Whiteboard, Red packet, Events, Game, Tournament (groups-only disabled + toast), Kanban — web chat-room.tsx:2519-2634. Poll/Schedule/Topic/Effects/Commands/Stage/Space rows already exist or stay as-is. Reminders surface via message long-press action "Remind me…" + `/remind` slash command parity (relative time parse `parseRelativeReminder`) + due badge; Leaderboard via room info sheet row (web group-info-sheet.tsx) — native: ChatRoom header (groups) → LeaderboardSheet; DM rooms hide it.
- **Whiteboard canvas**: native Canvas (Android Compose Canvas + pointerInput; iOS Canvas/Path) on normalized coords; batch strokes (debounced, ≤40/call), undo (own-latest), clear (two-tap confirm), since-delta merge at 900 ms while sheet open, 0..1 clamp, stylus support free.
- **Kanban**: 3 fixed columns, native drag-reorder → PATCH position, message→card action on message long-press ("Add to board"), add-card per column, assignee picker (room members), delete per rules; 1500 ms poll while sheet open, paused when app backgrounded.
- **Events**: upcoming asc + past desc merged ≤50; RSVP chips Going/Maybe/Can't; check-in button inside window; creator does NOT auto-RSVP; delete creator/admin.
- **Reminders**: sheet lists due + upcoming; create = note (≤280) + relative parse ("in 20m", "tomorrow 9am" parity with web parseRelativeReminder) or absolute picker; **local notification Tier 1**: Android WorkManager OneTimeWork (delay to remindAt) + foreground due-loop 30 s → notification + PATCH firedAt; iOS UNUserNotificationCenter requestAuthorization + UNCalendarNotificationTrigger at create/refresh + due-loop. Honest offline: local schedule fires offline; marking fired needs network.
- **Hub (both platforms)**: replace static tiles. Live wallet hero (coins/gems/streak/checkedInToday, count-up); Check-in (+streak bonus copy, 409 → honest toast); tiles → surfaces: Wallet (ledger), Transfer (@handle), Swap (rates + stats), Tasks (3-col personal kanban), Market (list/buy w/ escrowless atomic copy), Logs (stream ≤80, live append while open), Apps (100-app matrix from bundled JSON, category chips, search, install/connect, communities → real conversation → opens room, My apps = fan-out installs). Catalog + taglines bundled verbatim from hub-catalog.ts as JSON asset per platform (single source: generate once, commit).
- **Caching/offline**: one generic snapshot cache table per platform (Android Room v9 `wave7_cache(key, json, updatedAt)`; iOS GRDB v7 same shape) — story_cache precedent. Wallet/tasks/board/events/reminders/standings/leaderboard read-through cached, stale-marked offline. Grab/transfer/buy/swap = network-required (honest fail). Catalog browsable offline.
- **No scope expansion**: no abandonment, no auto-end tournaments, no batch-installs endpoint, no whiteboard socket channel.
- **Copy**: verbatim web strings where extracted above; server error strings surface verbatim via existing error plumbing.
